01 — Overview

Executive Summary

The Kosmos platform transitions from a proof-of-concept capable of ~50–200 concurrent devices to a production architecture targeting 10,000+ sensors at 25Hz — equivalent to 250,000 data points per second sustained.

The production design introduces a streaming bus (NATS JetStream), a real-time Redis 7 cache, a dedicated WebSocket Gateway, and a batched Storage Worker (BullMQ). All existing REST API contracts, Mongoose data models, compliance certifications, and the visual workflow editor are carried forward unchanged.
